A new client gets a simple structured filter (CPV codes, keywords, notice types, regions, value range) evaluated against every notice already swept, and every new notice going forward -- the same shape as a portal's own advanced search. This is completely separate from Trifork's own 5-gate + AI system above, which stays exactly as it is. Every configured field must match (AND); any one value within a field is enough (OR). Leave a field blank for "no constraint."
